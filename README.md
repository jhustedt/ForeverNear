# forevernear.us

Static site, no build step. Structure:

```
index.html          → forevernear.us          (directory of all memorials)
zuki/index.html      → forevernear.us/zuki      (Zuki's memorial)
zuki/media/           photos & videos for Zuki
shared/style.css      shared theme (colors, type, layout)
shared/gallery.css    media grid + lightbox styles
shared/lightbox.js    click-to-view-in-browser behavior
CNAME                 tells GitHub Pages to serve this custom domain
```
