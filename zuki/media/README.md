Drop Zuki's photos and videos in this folder.

cover.jpg — used as her small portrait on the forevernear.us home page.
Add a file with this exact name and it will appear there automatically
(square-ish photos crop best, since it's shown as a circle).

Gallery photos/videos — suggested naming (matches the example tiles
already in ../index.html):
  photo-01.jpg, photo-02.jpg, ...
  video-01.mp4  + video-01-poster.jpg   (a still frame shown before the video is opened)

After adding a file, copy/paste one of the example <button class="gallery-item">
blocks in zuki/index.html and point data-src (and img src, for photos) at your
new filename. Keep file sizes reasonable (a few MB per photo, videos ideally
under ~50-100MB) so the page loads quickly — GitHub also has a 100MB per-file
hard limit.
